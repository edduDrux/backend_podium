# 🏆 Podium - Core Backend (Python)

O **Podium** é uma solução de Realidade Virtual (VR) integrada a Large Language Models (LLMs) desenvolvida como Trabalho de Conclusão de Curso (TCC) em Ciência da Computação. O objetivo é fechar a lacuna entre a simulação visual de ambientes e o feedback semântico sobre o conteúdo de uma apresentação.

## ⚙️ Funcionalidades Principais
- **Ingestão Multimodal:** Processamento de documentos (PDF, PPTX, DOCS) para contextualização da IA.
- **Processamento de Áudio:** Transcrição de apresentações de até 30 minutos via Speech-to-Text (STT).
- **Arguição Dinâmica:** Geração de perguntas contextuais baseadas no conteúdo apresentado e no perfil escolhido.
- **Perfis de Simulação:** Configurações específicas para Bancas Acadêmicas, Entrevistas de Emprego e Grandes Auditórios.

## 🛠️ Tecnologias
- **Linguagem:** Python 3.10+
- **Framework:** FastAPI (escolhido pela alta performance e suporte a tipos/assincronismo)
- **IA/LLM:** Integração com OpenAI GPT ou Google Gemini
- **STT:** Whisper ou Google Speech-to-Text
- **Arquitetura:** Microservices-ready com processamento assíncrono
